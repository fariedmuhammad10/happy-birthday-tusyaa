# 🍓💌 happy birthday, tusyaa

Website ulang tahun dari **payittt** buat **tusyaa** bergaya *"you've got new emails"* dengan warna strawberry pink & soft green.

Live: https://fariedmuhammad10.github.io/happy-birthday-tusyaa/

- `index.html`, `style.css`, `script.js` — websitenya (semua teks, nama, foto, alasan & voucher bisa diedit di bagian `CONFIG` paling atas `script.js`)
- `photos/` — foto-foto tusyaa
- `assets/qr-heart.png` — QR code bentuk hati strawberry yang ngebuka website ini
- `assets/og.jpg` — gambar preview pas link dikirim di WhatsApp
- `tools/` — script buat proses foto, bikin QR & preview image (`npm i` lalu `node qr.js`)
